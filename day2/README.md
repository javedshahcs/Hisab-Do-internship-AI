# HisabDo AI/ML Internship - Day 2
## Student Data Analysis using Python & Pandas

This repository contains my submission for **Day 2** of the HisabDo AI/ML Internship Bootcamp.

### 🎯 Project Objective
To practice Python fundamentals and basic data handling using Pandas by analyzing a student dataset.

### 📊 Dataset
The dataset contains information of 10 students with the following fields:
- **Name**: Student Name
- **Age**: Student Age  
- **Course**: Degree Program (BSCS, BBA, BSIT, BSE)
- **Marks**: Marks obtained out of 100

### ✅ Tasks Completed
1. **Display all students** - Show complete DataFrame
2. **Filter students** - Display students with marks > 70
3. **Calculate average marks** - Mean of all marks
4. **Find highest scorer** - Student with maximum marks
5. **Find lowest scorer** - Student with minimum marks  
6. **Total students** - Count of total students in dataset

### 🛠️ Tech Stack
- **Language**: Python 3.x
- **Library**: Pandas
- **Concepts Used**: Lists, Dictionaries, DataFrames, Filtering, Aggregation
